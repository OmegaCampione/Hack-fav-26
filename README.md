# PeakCycle

PeakCycle conecta supermercados, padarias e mercearias a pessoas da comunidade e ONGs para doar ou vender a preço simbólico alimentos próximos da validade.

Projeto desenvolvido para o hackaton (26)

## Dev

Você precisa de Node.js e npm — [instale com nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <https://github.com/OmegaCampione/Hack-fav-26>
cd <Hack-fav-26>
npm i
npm run dev
```
